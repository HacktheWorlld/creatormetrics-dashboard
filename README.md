# CreatorMetrics — Video Analytics

Import a CSV of video performance metrics and compare engagement rates.

## Run

Open `index.html` in a modern browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000. No dependencies or accounts required.

## Portfolio description

A working, local-first prototype demonstrating front-end development and digital content production workflows.

## Limitations

This is a starter project, not a production service. No cloud accounts, social publishing integrations, or external analytics are included.
